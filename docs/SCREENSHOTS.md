## 与 Pixso 的对应关系

| 原稿区域 | 实现方式 |
| --- | --- |
| 1 启动，2–9 引导 v1/v2 | 启动展示与四步 v1 引导；v2 是未重复制作的视觉备选 |
| 10–17 登录 / 偏好 / 找回 | 登录、注册、分类、经验、技能、找回、验证、重设 |
| 18 / 19 Home v1/v2 | v1 首页为主，合入分类探索与完善资料入口 |
| 20–23 通知 / 搜索 / 筛选 / 推荐 | 独立通知页、双结果标签、筛选弹层与推荐列表 |
| 24 / 25 短 / 长职位详情 | 一个可完整滚动的详情页面 |
| 26–33 投递 / 成功 / 完善资料 | 简洁与完整表单、投递成功、公司机会、身份 / 工作 / 技能表单 |
| 34–36 探索 / 结果 / 空状态 | 探索分类、组合查询、结果与空状态 |
| 37–42 我的投递 / 各阶段 / 拒绝 / 空状态 | Active / Rejected、参数化阶段页、无投递状态 |
| 43–50 资料与设置 | 个人中心、完整资料、编辑、语言、安全、关于、FAQ、退出弹层 |

原设计导出图见 [design](design/)。它们与应用运行截图分开保存。后续修改 UI 后可执行 flutter test test/screenshots_test.dart --update-goldens 更新主截图；运行 integration_test 可更新 Android 截图。
